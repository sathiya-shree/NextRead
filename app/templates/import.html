Import your library

From Goodreads

  1. On goodreads.com (desktop site — the export isn't in the mobile app), go to My Books
  2. In the left sidebar under Tools, click Import and Export
  3. Click Export Library and download the CSV once it's ready

From Fable

Fable doesn't have an official export feature yet. The community-built Fable Xport Chrome extension can export your Fable library as a Goodreads-format CSV — run that first, then upload the file it gives you below. (It's an unofficial third-party tool, not run by Fable or Shelfie, so use your own judgment.)
